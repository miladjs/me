# صفحهٔ شخصی میلاد رکن‌الدینی

رزومهٔ تک‌صفحه‌ای فارسی با HTML، CSS و JavaScript، منتشرشده روی GitHub Pages.

## اجرا

فایل `index.html` را در مرورگر باز کنید. سایت به ابزار ساخت یا وابستگی اجرایی نیاز ندارد.

اطلاعات رزومه و تصویر پروفایل از [GitHub میلاد](https://github.com/miladjs) برگرفته شده‌اند. فونت Vazir با مجوز SIL OFL 1.1 از [پروژهٔ اصلی](https://github.com/rastikerdar/vazir-font) در پوشهٔ `assets` قرار دارد.
